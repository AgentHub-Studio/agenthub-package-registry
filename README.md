# AgentHub Package Registry

**Package Management System** - Export, import e versionamento de packages (.ahpkg).

## Responsabilidades
- Exportar componentes como packages (.ahpkg)
- Importar e validar packages
- Gerenciar dependências
- Versionamento semântico
- Integração com MinIO para storage

## API
- POST /api/v1/packages/export
- POST /api/v1/packages/import
- GET /api/v1/packages
